01
Telegram API Key ရယူ ONE TIME
1
my.telegram.org သွားပါ
my.telegram.org ကိုဖွင့်ပြီး phone number နဲ့ login ဝင်ပါ
2
API development tools နှိပ်
Login ဝင်ပြီးနောက် API development tools ကိုနှိပ်ပါ
3
Application ဖန်တီး
App name ထည့်ပြီး Create application နှိပ်ပါ
💡 ရလာသော api_id (ဂဏန်း) နဲ့ api_hash (string) နှစ်ခုလုံး မှတ်ထားပါ
02
Bot Token ရယူ
1
BotFather သွားပါ
Telegram မှာ @BotFather ကိုဖွင့်ပြီး /newbot ပို့ပါ
2
Bot name & username ထည့်ပါ
BotFather က bot display name တောင်းမည်၊ ထို့နောက် @username (bot_ ဖြင့်ဆုံးရမည်) တောင်းမည်
3
Token မှတ်ထားပါ
BotFather ပေးသော token (ဥပမာ: 1234567890:AAFMe...) ကို မှတ်ထားပါ
4
Target Channel ထဲ Admin ထည့်ပါ
Bot ကို target channel ထဲ invite လုပ်ပြီး Post Messages permission ပေးပါ
03
Session String Generate လုပ် LOCAL MACHINE
1
Telethon install လုပ်ပြီး script run ပါ
Terminal/Command Prompt ဖွင့်ပြီး အောက်ပါ command run ပါ
bash / terminal 
pip install telethon
python generate_session.py
2
Input fields တွေ ဖြည့်ပါ
Script က အောက်ပါ input များ တောင်းမည်
terminal prompt 
# api_id (ဂဏန်းသာ)
TELEGRAM_API_ID: 12345678

# api_hash
TELEGRAM_API_HASH: abc123def456...

# ဖုန်းနံပါတ် (country code ပါ)
Phone number: +959xxxxxxxx

# Telegram ပေးပို့သော OTP
Enter code: 12345

# 2FA password (မရှိရင် Enter သာနှိပ်)
Password:
⚠️ Terminal မှာ ပေါ်လာသော long string (1BVtsO...) ကို copy ထားပါ — ဒါက TELETHON_SESSION_STRING ဖြစ်သည်
🔒 ဤ string = နင့် Telegram account login ထားတာနဲ့ တူသည်။ GitHub မတင်ရ၊ Secrets ထဲသာ ထည့်ပါ
04
Channel ID ရှာ
A
@userinfobot ဖြင့် ရှာနည်း
Channel မှ post တစ်ခုကို @userinfobot ဆီ forward လုပ်ပါ — numeric ID ပြောင်းပေးမည်
B
Username ဖြင့် တိုက်ရိုက်သုံး
Public channel ဆိုရင် @channelname ပုံစံ တိုက်ရိုက်သုံးလို့ ရသည်

Numeric ID ဆိုရင် -100 prefix ပါသည် — ဥပမာ: -1002436922774

06
Secrets ထည့်
→
Space Settings → Repository secrets မှာ အောက်ပါ secrets တွေ ထည့်ပါ
SECRET KEY ဘယ်မှာ ရသလဲ STATUS
TELEGRAM_API_ID my.telegram.org → API development tools REQUIRED
TELEGRAM_API_HASH my.telegram.org → API development tools REQUIRED
TELETHON_SESSION_STRING Step 03 မှ generate_session.py ထုတ်ပေးသော long string REQUIRED
TELEGRAM_BOT_TOKEN @BotFather ထံမှ ရသော token REQUIRED
SOURCE_CHANNEL_ID Watch ချင်သော channel ID/username (comma-separated: @ch1,@ch2) REQUIRED
TARGET_CHANNEL_ID Post တင်မည့် channel numeric ID (ဥပမာ: -1002218930216) REQUIRED
BLACKLIST_KEYWORDS Skip ချင်သော စကားလုံး comma-separated (ဥပမာ: ads,promo,sponsored) OPTIONAL
CUSTOM_TEXT Caption အောက်မှာ ထည့်မည့် text (ဥပမာ: channel credit) OPTIONAL
✅ Secrets အားလုံး ထည့်ပြီးနောက် Space က auto-rebuild လုပ်မည်။ Logs tab မှာ Bot is running. Press Ctrl+C to stop. ပေါ်လာရင် အဆင်ပြေပြီ
!
Troubleshooting
AUTH_KEY_UNREGISTERED
Session string ကုန်သွားပြီ။ generate_session.py ကို ထပ် run ပြီး Secret update လုပ်ပါ
Bot မတင်နိုင်
Bot ကို target channel ထဲ admin ထည့်ပြီး Post Messages permission စစ်ပါ
Source channel မမြင်
Channel public ဖြစ်ရမည် (သို့) user account က member ဖြစ်ရမည်
ChatForwardsRestricted
Source channel မှာ "Restrict saving content" ဖွင့်ထားသည်။ API-level bypass မရှိ — channel ပြောင်းပါ
Space crash / restart
HuggingFace Space Logs tab မှာ error message စစ်ပါ၊ Secrets တစ်ခုခု 빠kte နေသလား စစ်ပါ
FloodWaitError
Bot က Telegram rate-limit ကျသည်။ Log မှာ wait time ပေါ်မည် — auto retry လုပ်ပေးသည်
